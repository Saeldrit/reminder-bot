# Saylo Sprint Reminder Bot

Автоматические напоминалки по спринтам в Telegram-группу.
Расписание задаётся шаблоном спринта, переносы/отмены — через overrides в JSON.

## Как работает

```
GitHub Actions (каждый будний день 11:00 МСК)
  → проверяет: сегодня день напоминалки?
  → учитывает переносы из overrides
  → если да — шлёт в Telegram
  → если нет — тихо завершается
```

## Структура config.json

### Шаблон спринта

```json
{
  "sprint": {
    "start_date": "2026-03-16",   // дата начала ПЕРВОГО спринта (понедельник)
    "length_days": 21,             // длина спринта в днях
    "timezone_offset_hours": 3     // UTC+3 (Казань/Москва)
  }
}
```

### Напоминалки

Каждая привязана к дню спринта через `day_offset` (0 = первый день спринта):

| day_offset | День            | Напоминалка |
|------------|-----------------|-------------|
| 4          | Пт, неделя 1   | Закрыть задачу на 2 дня |
| 8          | Вт, неделя 2   | Проверить 40% готовности |
| 10         | Чт, неделя 2   | Закрыть на 2 дня |
| 15         | Вт, неделя 3   | Закрыть последнюю задачу |

### Переносы и отмены (overrides)

Праздник? Просто добавь строку:

```json
{
  "overrides": [
    {
      "original_date": "2026-05-01",
      "action": "move",
      "new_date": "2026-04-30",
      "reason": "Праздник 1 мая"
    },
    {
      "original_date": "2026-06-12",
      "action": "skip",
      "reason": "День России, пропускаем"
    }
  ]
}
```

**`action: "move"`** — перенос на другую дату.
**`action: "skip"`** — просто не отправлять.

## Настройка

### 1. Telegram-бот

1. [@BotFather](https://t.me/BotFather) → `/newbot`
2. Добавь бота в группу как администратора
3. Получи `chat_id` группы

### 2. GitHub

#### Secrets:
| Имя                  | Значение        |
|----------------------|-----------------|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |

#### Variables:
| Имя                | Значение            |
|--------------------|---------------------|
| `TELEGRAM_CHAT_ID` | ID группы или `@имя` |

## Тестирование

### Ручной запуск в Actions

**Actions → Sprint Reminder Bot → Run workflow**

Параметры:
- `dry_run: true` — сгенерирует сообщение, но не отправит
- `fake_date: 2026-03-20` — симуляция конкретной даты

### Локально

```bash
export TELEGRAM_BOT_TOKEN="123456:ABC..."
export TELEGRAM_CHAT_ID="@saylo_team"
export DRY_RUN="true"
export FAKE_DATE="2026-03-20"

python reminder_bot.py
```

## Как менять расписание

| Ситуация | Что делать |
|----------|-----------|
| Праздник, перенести | Добавить override с `action: "move"` |
| Праздник, пропустить | Добавить override с `action: "skip"` |
| Изменить текст | Отредактировать `message` в `reminders` |
| Изменить день напоминалки | Изменить `day_offset` |
| Новый спринт | Ничего — спринты автоциклятся |
| Поменялась длина спринта | Изменить `length_days` и `day_offset`-ы |

Всё редактируется прямо через GitHub UI → Edit file → Commit.
